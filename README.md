# Cross-Lender Private Credit Valuation Monitor

A research project for comparing private credit fair-value marks across lenders using public SEC EDGAR filings.

## Overview

The project ingests BDC investment schedules, identifies records referring to the same borrower and facility, and compares reported fair values as a percentage of par.

In active development.
